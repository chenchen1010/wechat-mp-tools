# 配图提示词与当前 Agent 协作

适用于封面、正文插图和多张贴图。这个 Skill 只规划配图和撰写提示词；图片由用户当前 Agent 的可用生图能力生成，例如用户在 WorkBuddy、豆包等环境中实际启用的图片工具。先检查当前会话有哪些可用能力，不假定所有客户端或账号都支持生图。

## 从正文到配图

1. 阅读文章/贴图文案及已有素材，为每张必要的图片确定用途、对应段落或展示顺序。用户已经给出图片时优先复用。
2. 写出可以直接交给生图工具的提示词。主体、动作/场景和视觉信息必须来自内容；整组图片保持一致的风格、配色与人物/产品外观。参考图片仅在可用且符合用户意图时交给图片工具。
3. 用户要求自动配图时，当前 Agent 直接用已提供的生图能力执行；遵守该工具实际的参数、费用和授权要求。不要要求用户另配某个固定供应商的 Key，也不把无关公众号凭证发给图片工具。
4. 当前 Agent 无法生图时，交付提示词清单和目标文件名，说明缺少图片生成能力，待用户生成后继续；不能把提示词或占位图说成生成完成。
5. 取得真实图片，按工具允许的方式保存到本地 PNG/JPEG。检查能否完整解码、主体是否正确、文字是否清晰、比例是否适合、边缘裁切是否合理。发现问题时先修正对应图片，保留已完成的其他图片。
6. 将生成图片用于最终预览：文章封面填 `cover` / `--cover`，正文用相对文件路径插入 Markdown/HTML；贴图按顺序传给 `--images`。预览合格后按用户授权推送草稿并回读。

## 每张图的交付格式

- **编号和用途**：如 cover / 封面，body-01 / 第一节之后，card-02 / 第二张贴图。
- **比例**：封面示例16:9，横向示意图示例4:3，贴图示例3:4；按内容和用户要求选择，封面主体预留裁切空间。
- **提示词**：具体主体、场景/动作、构图、风格、色彩、光线；需要图中文字时逐字给出，文字多时优先分图。
- **参考素材**：如需保持产品/人物一致性，列出用户提供的本地素材路径；没有则省略。
- **目标文件**：如 `images/cover.png`、`images/body-01.png`、`images/card-02.png`。
- **状态**：提示词已准备 / 正在生成 / 图片已检查；只在拿到真实图片后推进状态。

例如，文章主题为“周末读书，把注意力留给一件事”：

> 为这篇文章制作一张16:9横向封面。清晨自然光下的木质书桌，一本打开的书和一只白色茶杯，窗边柔和植物投影。主体位于中央，四周保留裁切空间；温暖米白与低饱和绿色，真实摄影质感，画面安静。不要文字、水印或额外品牌标志。保存为 images/cover.png。

提示词应根据实际文章重写，不重复套用这个例子。宿主工具返回的任务号或链接不等于最终图片已准备好。
