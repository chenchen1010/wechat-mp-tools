# 公众号文章与贴图发布

把排版好的文章或一组图片送进你自己的公众号草稿箱，省去逐张上传和反复粘贴。你可以先预览和修改，再决定是否发布。

## 买家首次使用

1. 打开你自己的公众号后台，在开发配置的 **IP 白名单** 中追加服务方公网 IP：**`8.153.207.214`**，保留原有条目。
2. 按服务方的私密配置流程绑定自己的公众号。AppID、AppSecret 用于服务器代你连接微信，不要放进公开文档或 Skill 包。
3. 使用服务方为你单独开通的服务地址、访问凭证和账号别名填写本地 env 文件。不会默认使用开发者的公众号。
4. 完成连接检查后，先推送一条测试草稿，并在自己的公众号后台查看。

买家共用服务方的公网出口 IP，各自发布到自己绑定的公众号。购买后的自动开户/绑定入口尚未在本仓库实现，当前需服务方先完成配置。

## 文章与贴图

- **文章**：先排版，再通过固定 IP 服务上传正文图片、封面和草稿；本机直连微信的发布命令不属于这一方案。
- **贴图/小绿书**：提供标题、纯文本和1–20张有序 PNG/JPEG。先预检，再上传；回读核对内容、数量和顺序。
- **已有草稿**：修改前先读最新内容，保留用户手工编辑；仅修改指定部分。

完整操作、参数、图片限制和异常恢复见 [SKILL.md](SKILL.md)。贴图依赖安装：`python3 -m pip install -r requirements.txt`。

`publish.py` 默认文章模式 `--type news -m article.md`，仅含简易 Markdown 兜底；`--type newspic` 是贴图模式。真实推送必须提供账号别名或在私有 env 中配置 `WECHAT_MP_API_ACCOUNT_DEFAULT`，缺失时不会自动选择账号。

## 服务方部署注意

现有代理是进程级共享令牌与静态账号列表，尚未实现多买家权限隔离。不能将开发者现有服务的同一个令牌发给所有买家。

当前可用部署方式：每位买家独立代理实例、独立令牌、独立端口和公众号配置，共用同一公网出口 IP。统一多买家服务则需要先实现服务端账号权限绑定并验收。详见 [服务器配置模板](../../../api-server/.env.example)。

## 排错

- `40164 invalid ip`：确认服务方出口 IP 已在当前公众号白名单中；不要添加买家电脑 IP 来代替。
- 身份验证失败：检查买家专用服务配置是否已开通，不能借用开发者配置继续推送。
- 草稿创建结果未知：先查原回执和草稿箱，不换回执重复提交。
- 创建成功但回读失败：使用原回执继续查询，不重新创建。

草稿成功不代表已公开发布；正式展示还应在微信后台预览。
